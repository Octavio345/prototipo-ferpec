# Ferpec Commerce

Site institucional e vitrine digital da Ferpec Commerce, desenvolvido com Next.js, React e TypeScript.

## Requisitos

- Node.js 22 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Validação de produção

```bash
npm run build
npm start
```

## Publicação

O projeto utiliza Next.js padrão e pode ser importado diretamente pela Vercel. O arquivo `vercel.json` mantém o framework e o comando de build configurados.

As alterações locais somente chegam ao GitHub ou à Vercel depois de serem enviadas manualmente pelo responsável pelo projeto.
